# Security policy

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/2techy/inknest/security/advisories/new) to report a suspected security issue in InkNest. Include the affected version or commit, reproduction steps, expected impact and a minimal synthetic example when possible.

Keep exploit details out of public issues and Discussions while a report is being investigated. Do not attach private books, document URIs, source databases, signing keys or passwords. If a credential was exposed, revoke or rotate it through its provider.

## Supported versions

InkNest is in active development. Security fixes target the current development code; older development builds do not have a separate maintenance branch. Update to a build containing the relevant fix when it becomes available.

For ordinary bugs and setup questions, use [Issues](https://github.com/2techy/inknest/issues) or [Discussions](https://github.com/2techy/inknest/discussions).
